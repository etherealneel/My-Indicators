# ETHEREALNEEL TRADERS STRUCTURE INDICATOR

A custom TradingView indicator developed and maintained by **ETHEREALNEEL** for market structure analysis, trading level identification, and chart-based technical analysis.

This repository contains the Pine Script source code of my personal indicator — the only indicator I use and actively develop for my own trading. It is continuously refined, updated, and customized according to my trading approach and market analysis.

## Overview

The indicator is designed to map market structure, identify key price levels, and provide additional analytical tools directly on the TradingView chart.

### Features

- **Market Structure** — Swing Highs, Swing Lows, Break of Structure (BOS), and Change of Character (CHOCH).
- **Trading Levels** — TJL 1, TJL 2, QML, SBR, RBS, Double Top (DT), and Double Bottom (DB).
- **ISS System** — Internal Structure Shift logic with multiple levels, scenarios, and customizable controls.
- **A+ Levels** — Filtering options for selected high-priority trading levels.
- **SMC Tools** — Optional Fair Value Gaps (FVG), Order Blocks (OB), and Kill Zones.
- **EMA** — Customizable Exponential Moving Average with optional smoothing and Bollinger Bands.
- **Multi-Timeframe Trend Dashboard** — Trend visualization across multiple configurable timeframes.
- **Level Accuracy Analyzer** — Tracks level performance using configurable win and loss targets.
- **Alerts** — Notifications for selected level formations across multiple timeframes.
- **Customization** — Configurable visibility, colors, level limits, display settings, and analysis parameters.

## Platform & Language

- **Platform:** TradingView
- **Language:** Pine Script v6
- **Type:** Overlay Indicator
